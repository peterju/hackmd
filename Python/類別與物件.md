# 類別與物件
![image](https://hackmd.io/_uploads/Hyc__LdSa.png)

## 簡介
Python 一切皆為物件(object)，而物件的定義來自於類別(class)，所以類別是物件的藍圖。

> Everything in python is object.
Classes, functions, and even simple data types, such as integer and float

物件內的變數稱為屬性(attribute)，而操作物件的函式稱為方法(method)，根據類別產生的物件稱之為實例(instance)
> Everything object can have attributes and methods.
> * Attribute: A variable stored in an instance or class is called an attribute.
> * Method: A function stored in an instance or class is called a method.

1. Python 的類別中屬性有【類別屬性】和【實例屬性】 2 種，而方法有【類別方法】、【實例方法】和【靜態方法】 3 種。
2. 因為[鴨子型別](https://zh.wikipedia.org/wiki/%E9%B8%AD%E5%AD%90%E7%B1%BB%E5%9E%8B)的考量，Python 不需要介面 (interface)。
3. 物件導向語言中的建構子(Constructor)，在 Python 是用 `__init__()` 函式。 
:::info
:star: 什麼是鴨子型別？

鴨子型別是一種判斷物件是否適合某個用途的方式，不是依賴它的「類型」，而是依賴它的「行為」。換句話說，只要物件具有某些需要的方法或屬性，就可以使用它，而不需要顯式檢查它的類型。

這個概念來自一句話：

> 「如果它走起來像鴨子、游泳起來像鴨子、叫起來也像鴨子，那麼它就是鴨子。」

在程式設計中，只要某個物件有我們需要的方法或屬性，我們就可以把它當成我們想要的類型來用，而不必確認它的具體類型。
:::

## 屬性
類別有二種屬性，分別是：
1. 類別屬性（Class Attribute）： 定義在類別中，對該類別的所有實例共享，使用 ClassName.attribute_name 的方式取用。
2. 實例屬性（Instance Attribute）： 定義在實例中，每個實例都有自己的一份屬性，使用 self.attribute_name 的方式取用。

在 Python 中，屬性預設是公開的（public），也就是說可以直接從類別或實例外部訪問和修改這些屬性。請執行以下範例就能更清楚屬性了。
```python=
# 類別定義
class Car:
    color = "Red"  # 類別屬性

    def __init__(self, model):
        self.model = model  # 實例屬性


car1 = Car("Model S")  # 建構時設定實例屬性
car2 = Car("Model X")  # 建構時設定實例屬性

# 修改類別屬性，會影響所有實例(物件)，就算在實例已經建立之後
Car.color = "Blue"  # 設定類別屬性
print(Car.color)  # Blue
print(car1.color)  # Blue (繼承自類別屬性)
print(car2.color)  # Blue (繼承自類別屬性)

print()

# 修改實例屬性，只會影響該實例(物件)
car1.model = "Benz"
print(car1.model)  # Benz
print(car2.model)  # Model X
```

### 封裝層級
Python 的封裝層級，表面上也如同 C++, Java, C# 等語言有 public / protected / private 這三個層級，但 protected 只是「約定俗成」，並未實際支援，所以實際上只有 public 和 private 兩層。
- public：名稱前無前綴底線。完全開放，物件可在外部自由存取，封裝層級最低。
- protected：名稱前綴一條底線。請記住這個層級只是「慣例」，Python的語法並無本功能。僅物件及其子孫的內部才可存取，封裝層級中等。
- private：名稱前綴兩條底線。只有類別自身內部方可存取，封裝層級最高。

```python=
class Tree:
    def __init__(self, breed, age, height):
        """ 建構子"""
        self.breed = breed                   # public: 名稱前面沒有底線。
        self._age = age                      # protected: 前綴一條底線(無實質保護效果)。
        self.__height = height               # private: 前綴兩條底線(有實質保護效果)。

    def show_info(self):
        """ 顯示物件屬性的方法 """
        print(f'  breed(public):   {self.breed}')
        print(f'  age(protected):  {self._age}')
        print(f'  height(private): {self.__height}')


# 透過類別 Tree 建立一個物件(實例)。
laozi = Tree('cedar', 2593, 59) # 以Tree()類別為藍本，建立一棵名為laozi(老子神木)的樹，樹種為 cedar，樹齡 2593 歲。

print('\n．透過呼叫 laozi.show_info() 方法取值。private 屬性也可存取：')
laozi.show_info()

print('\n．用「物件.屬性」表示法取值。只能存取 public 和 protected 層級屬性：')
print("  laozi.breed：", laozi.breed)
print("  laozi._age：", laozi._age)
# 以下這行會出現錯誤，因為 __height 是 private 屬性
print("  laozi.__height：", laozi.__height)  # AttributeError: 'Tree' object has no attribute '__height'
```

方法的封裝層級也和屬性一樣，請看以下範例：
```python=
class BankAccount:
    def __init__(self, owner: str, balance: float):
        self.owner = owner  # 公開屬性
        self._account_type = "存款"  # 受保護屬性
        self.__balance = balance  # 私有屬性
    
    def _check_balance(self) -> bool:
        """受保護方法"""
        return self.__balance > 0

    def __calculate_interest(self) -> float:
        """私有方法"""
        return self.__balance * 0.02

    def get_balance(self) -> float:
        """公開方法，用於存取私有屬性"""
        return self.__balance

    def deposit(self, amount: float) -> None:
        """公開方法，用於修改私有屬性"""
        if amount > 0:
            self.__balance += amount
        else:
            raise ValueError("存款金額必須大於 0")


account = BankAccount("John", 1000)
print(account.get_balance())  # 使用公開方法存取私有屬性: 1000
account.deposit(1000)  # 使用公開方法修改私有屬性
print(account.get_balance())  # 使用公開方法存取私有屬性: 2000
print(account._check_balance())  # 使用受保護方法: True
# 以下這行會出現錯誤，因為 __calculate_interest() 是 private 方法
print(account.__calculate_interest())  # AttributeError: 'BankAccount' object has no attribute '__calculate_interest'
```

:::warning
Python類別中保護層級的屬性，只是「約定俗成」：大家有個默契，前綴一條底線的屬性就不要用「物件.屬性」的方式修改了。實際上這條前綴底線完全沒有實質保護效果。
:::

## 方法
類別有三類方法，分別是：
1. 實例方法（Instance Method）： 定義在類別中並以 self 作為第一個參數，用來操作實例屬性，僅能由實例呼叫，使用 Instance.method_name() 的方式呼叫。
▶ 使用時機：當你需要取用、操作實例的屬性和方法時使用。
2. 類別方法（Class Method）： 使用 @classmethod 裝飾器定義，第一個參數通常是 cls，用來表示類別本身，能夠取用和修改類別屬性，使用 ClassName.method_name() 或者 Instance.method_name() 的方式呼叫。
▶ 使用時機：當方法需要取用或修改類別本身的屬性時，但不需要實例的屬性時使用。
3. 靜態方法（Static Method）： 使用 @staticmethod 裝飾器定義，與類別和實例無關，不需要引入 self 或 cls 參數，可以由類別或實例呼叫，但因可無須實例就能使用，實際上使用都是用類別.方法的方式呼叫。
▶ 使用時機：當方法與類別或實例無關，並且不需要取用類別或實例的屬性時使用。

```python=
class Car:
    """代表汽車的類別"""    
    # 類別屬性
    color = "Red"

    # 方法(Methods)
    # 1. 建構子(Constructor)
    def __init__(self, color: str = None, model: str = None):
        """汽車類別的建構子。
        Args:
            color (str, optional): 汽車的顏色。預設為 None。
            model (str, optional): 汽車的型號。預設為 None。
        """
        self.color = color if color is not None else Car.color  # 使用類別屬性作為預設值
        self.model = model  # 可透過建立物件時設定的實例屬性

    # 2. 操作方法
    def display_info(self) -> str:
        """實例方法，顯示汽車資訊。"""
        return f"型號：{self.model}，顏色：{self.color}"

    @classmethod
    def update_color(cls, new_color: str):
        """類別方法，用於更新所有汽車的顏色。"""
        cls.color = new_color

    @staticmethod
    def check_model_length(model: str) -> bool:
        """靜態方法，檢查汽車型號名稱是否大於 5 個字元。"""
        return len(model) > 5

# 物件(Object) = 類別的實例化
# 建立物件時只設定 model，使用類別屬性作為預設顏色
car1 = Car(model="Toyota")
print(car1.display_info())  # 輸出: 型號：Toyota，顏色：Red

# 建立物件時同時設定 color 和 model
car2 = Car(color="Blue", model="Honda")
print(car2.display_info())  # 輸出: 型號：Honda，顏色：Blue

# 使用類別方法更新類別屬性 color
Car.update_color("Green")   # 將類別的 color 改為 Green
car1 = Car(model="Toyota")
car2 = Car(color="Blue", model="Honda")
print(car1.display_info())  # 輸出: 型號：Toyota，顏色：Green
print(car2.display_info())  # 輸出: 型號：Honda，顏色：Blue

# 使用靜態方法檢查模型名稱長度
print(Car.check_model_length("Ford"))     # 輸出: False
print(Car.check_model_length("Mercedes")) # 輸出: True

# isinstance() 可判斷指定物件是否為指定類別的實例
print(isinstance(car1, Car)) # 判斷 car1 是否為 Car 類別的物件, 輸出: True
print(type(car1))            # 返回物件的類別, 輸出: <class '__main__.Car'> 
print(dir(car1))             # 列出物件的屬性與方法
```

:::success
:star: Python 對類別的慣例

1. 類別名用【名詞】，字首大寫，其餘小寫
2. 屬性名用【名詞】，小寫命名，若由多個單詞組成，使用底線 _ 連接
3. 方法名用【動詞】，小寫命名，若由多個單詞組成，使用底線 _ 連接
4. 方法第一個參數名必須與 `__init__()` 第一個參數名相同，通常叫 self 或 this，代表實例化後的物件本身
:::

### 魔術方法（Magic Methods）
魔術方法讓 Python 的類別可以擴展和重載常見的操作，提供了極大的靈活性與可讀性。利用這些方法，你可以讓自己的類別像內建的資料型別一樣易用。

魔術方法是以雙底線開頭和結尾的特殊方法，這些方法可以讓類別具備特殊的行為，像是初始化、比較、運算元重載等，常見的魔術方法如下：

#### 1. `__init__(self, ...)`
這個方法在類別的實例化（物件建立）時自動被呼叫，用來初始化物件的屬性。
```python=
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

p = Person("Alice", 30)  # `__init__` 被呼叫
```

#### 2. `__str__(self)`
這個方法定義當物件使用 print() 或 str() 函數時，應該回傳的字串。
```python=
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __str__(self):
        return f'{self.name} is {self.age} years old'

p = Person("Alice", 30)
print(p)  # 輸出: Alice is 30 years old
```

#### 3. `__repr__(self)`
這個方法返回一個物件的正式字串表示，通常用來在控制台輸出或除錯時呈現，目標是提供一個精確的字串，能夠通過 eval() 來重新建立此物件。
```python=
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __repr__(self):
        return f'Person(name={self.name}, age={self.age})'

p = Person("Alice", 30)
print(repr(p))  # 輸出: Person(name=Alice, age=30)
```

#### 4. `__len__(self)`
這個方法讓你能夠使用 len() 函數來取得物件的長度。通常在容器類別（如列表、集合等）中使用。
```python=
class MyList:
    def __init__(self, items):
        self.items = items

    def __len__(self):
        return len(self.items)

ml = MyList([1, 2, 3])
print(len(ml))  # 輸出: 3
```

#### 5. `__getitem__(self, key)`、`__setitem__(self, key, value)`和`__delitem__(self, key)`
這些方法分別定義物件如何透過中括號 [] 來進行取值、賦值和刪除操作。。
```python=
class MyDict:
    def __init__(self):
        self.data = {}

    def __getitem__(self, key):
        return self.data[key]

    def __setitem__(self, key, value):
        self.data[key] = value

    def __delitem__(self, key):
        del self.data[key]

md = MyDict()
md['name'] = 'Alice'  # `__setitem__` 被呼叫
print(md['name'])      # `__getitem__` 被呼叫，輸出: Alice
del md['name']         # `__delitem__` 被呼叫
```

#### 6. `__call__(self, *args, **kwargs)`
這個方法允許物件像函數一樣被呼叫。
```python=
class Greeter:
    def __call__(self, name):
        return f'Hello, {name}!'

greet = Greeter()
print(greet("Alice"))  # 輸出: Hello, Alice!
```

#### 7. `__add__(self, other)`等運算元重載
魔術方法可以用來定義運算元的行為。例如，`__add__` 用來定義 `+` 運算元。
```python=
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, other):
        return Point(self.x + other.x, self.y + other.y)

    def __repr__(self):
        return f'Point({self.x}, {self.y})'

p1 = Point(1, 2)
p2 = Point(3, 4)
print(p1 + p2)  # 輸出: Point(4, 6)
```

#### 8. `__eq__(self, other)、__lt__(self, other)`等比較運算
這些魔術方法用來定義物件之間的比較操作。例如，__eq__ 用來定義相等 (==)，__lt__ 用來定義小於 (<)。
```python=
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __eq__(self, other):
        return self.age == other.age

p1 = Person("Alice", 30)
p2 = Person("Bob", 30)
print(p1 == p2)  # 輸出: True (因為兩個人的年齡相同)
```

#### 9. `__enter__(self)` 和 `__exit__(self, exc_type, exc_value, traceback)`
這兩個方法主要用於上下文管理器中，通常在 with 語句中使用。
```python=
class MyContextManager:
    def __enter__(self):
        print("Entering context")
        return self

    def __exit__(self, exc_type, exc_value, traceback):
        print("Exiting context")

with MyContextManager():
    print("Inside context")
    
# 輸出:
# Entering context
# Inside context
# Exiting context
```

## 動態擴充與修改物件屬性和方法
Python 的物件可以在執行期間動態地新增屬性和方法。這個特性使得我們能夠靈活地擴展物件的行為。以下範例展示如何動態增加屬性與方法：
```python=
class MyApp:
    def __init__(self, name):
        self.name = name

# 建立一個 MyApp 實例
app = MyApp('MyFlaskApp')

# 我們可以在執行時新增屬性
app.version = '1.0'  # 動態添加屬性

# 我們還可以動態添加方法
def new_feature(self):
    print(f"{self.name} is running with new feature!")

app.new_feature = new_feature.__get__(app)  # 動態添加方法

# 呼叫動態添加的屬性和方法
print(app.name)       # MyFlaskApp
print(app.version)    # 1.0
app.new_feature()     # MyFlaskApp is running with new feature!
```
### 相依性注入 (Dependency Injectio; DI)
Python 因為其物件可動態擴充的特性，因此我們可以設計一個具有新功能的類別，然後簡單地實現相依性注入，以下模擬 Flask 中 CSRFProtect() 的功能。
```python=
class CSRFProtect:
    def __init__(self, app=None):
        if app is not None:
            self.init_app(app)

    def init_app(self, app):
        # 在這裡動態為 app 添加 CSRF 保護功能
        app.csrf_enabled = True  # 為 app 添加屬性
        app.verify_csrf = self.verify_csrf  # 為 app 添加方法

    def verify_csrf(self):
        print("CSRF token verified!")

# 建立一個 Flask 類似的應用程式物件
class MyFlaskApp:
    def __init__(self):
        self.name = 'FlaskApp'

# 初始化應用程式
app = MyFlaskApp()

# 初始化 CSRF 保護，並將 app 傳遞給 CSRFProtect
csrf = CSRFProtect(app)

# 現在 app 物件動態新增了 CSRF 保護功能
print(app.csrf_enabled)  # True
app.verify_csrf()        # CSRF token verified!
```
在 CSRFProtect 初始化後，app 不僅有了原本的屬性，還被動態添加了新的屬性（csrf_enabled）和新的行為（verify_csrf()）。這就是「動態擴展」的過程。這種設計在 Flask 的擴展機制中非常常見。例如，許多 Flask 擴展都提供類似的 init_app 方法，允許你將應用程式傳入，並對其進行動態擴展。這也是 Python 動態性質和靈活性的一個強大表現。

## 屬性裝飾器
當我們在類別中定義私有屬性，或者希望在屬性被讀取或修改時執行一些額外的操作，傳統的方法是使用 getter 和 setter。這樣雖然可行，但每次存取屬性時都需要呼叫這些方法，程式碼看起來會比較繁瑣。以下是使用 getter 和 setter 的範例：
```python=
class Circle:
    def __init__(self, radius):
        self._radius = radius  # 定義一個私有的實例屬性 _radius

    # 定義 getter 方法來獲取 radius
    def get_radius(self):
        return self._radius

    # 定義 setter 方法來設定 radius 並加入額外的檢查
    def set_radius(self, value):
        if value <= 0:
            raise ValueError("半徑必須大於 0")
        self._radius = value

# 建立 Circle 物件
c = Circle(5)

# 使用 getter 方法存取 radius
print(c.get_radius())  # 輸出: 5

# 使用 setter 方法來修改 radius
c.set_radius(10)
print(c.get_radius())  # 輸出: 10
```
屬性裝飾器是要實現物件導向中設計中的封裝，讓我們可以像設定或取用物件那樣簡單的存取屬性。屬性裝飾器主要有 3 種語法：
- Getter: @property
- Setter: @變數名稱.setter
- Deleter: @變數名稱.deleter

以下是使用屬性裝飾器的範例：
```python=
class Circle:
    def __init__(self, radius):
        self._radius = radius  # 定義一個私有的實例屬性 _radius

    # 使用 property 裝飾器定義 getter 方法
    @property
    def radius(self):
        return self._radius

    # 使用 setter 裝飾器來定義修改 radius 時的邏輯
    @radius.setter
    def radius(self, value):
        if value <= 0:
            raise ValueError("半徑必須大於 0")
        self._radius = value

# 建立 Circle 物件
c = Circle(5)

# 直接像存取屬性一樣來存取 radius
print(c.radius)  # 輸出: 5

# 直接像設置屬性一樣來修改 radius
c.radius = 10
print(c.radius)  # 輸出: 10
```
:::success
當使用屬性裝飾器時，屬性的存取變得更簡潔，因為不再需要為 getter 和 setter 定義不同的方法名稱，減少了程式碼的冗餘性。這種同名異式的設計讓開發者能更直觀地理解屬性的用途，因為所有操作都針對同一個屬性，只透過裝飾器來區分讀取、寫入或刪除。這不僅使代碼更清晰，還提高了可讀性，讓其他開發者更容易理解屬性的行為。
:::

## 資料類別（Data Classes）
Python 在 3.7 版本後，內建函式庫新增了 dataclass，讓定義類別變得更加簡潔和直觀，方便開發者因儲存資料要設計新類別（Class）時使用，@dataclass 是一個類別裝飾器，會自動為類別產生常用的方法，如 `__init__`、`__repr__` 和 `__eq__`，使程式碼更簡潔、可讀性更高，也更容易維護。

### 傳統類別寫法
在傳統的類別中，開發者需要手動定義初始化方法（__init__）、物件表示方法（__repr__）和比較方法（__eq__），這樣會導致程式碼冗長，尤其當類別只是用來儲存資料時。
```python=
class PointTraditional:
    def __init__(self, x: float, y: float):
        self.x = x
        self.y = y

    def __repr__(self):
        return f'Point(x={self.x}, y={self.y})'

    def __eq__(self, other):
        if isinstance(other, PointTraditional):
            return self.x == other.x and self.y == other.y
        return False

# 建立 PointTraditional 物件
p1 = PointTraditional(3.0, 4.0)
p2 = PointTraditional(3.0, 4.0)

print(p1)        # 輸出: Point(x=3.0, y=4.0)
print(p1 == p2)  # 輸出: True，因為兩個物件的屬性相同
```

### 使用 dataclass 的類別定義
若使用 dataclass，我們只需定義屬性，Python 會自動產生常用的方法，這使得程式碼更簡潔，同時保持了類別的完整功能。
```python=
from dataclasses import dataclass

@dataclass
class Point:
    x: float
    y: float

# 建立 Point 物件
p1 = Point(3.0, 4.0)
p2 = Point(3.0, 4.0)
print(p1)        # 輸出: Point(x=3.0, y=4.0)
print(p1 == p2)  # 輸出: True，因為兩個物件的屬性相同
```

### 其它使用 dataclass 的重點
#### 1. 屬性預設值
在 dataclass 中，屬性可以有預設值。當屬性需要複雜的預設值，或是不可變物件時，可以使用 field 來設置。default_factory 可以為可變物件提供預設值，例如 list 或 dict，避免所有物件共用同一個可變預設值。
```python=
from dataclasses import dataclass, field

@dataclass
class Circle:
    radius: float
    center: Point = Point(0.0, 0.0)  # 可以為物件的屬性設定預設值
    tags: list = field(default_factory=list)  # 使用 default_factory 設定可變物件的預設值

# 建立 Circle 物件
circle = Circle(5.0)
print(circle)  # 輸出: Circle(radius=5.0, center=Point(x=0.0, y=0.0), tags=[])
```

#### 2. 屬性不可變
預設情況下，dataclass 中的屬性是可變的。如果需要讓屬性不可變，可以使用 frozen=True 參數，這樣一旦物件被建立後，其屬性就無法修改：
```python=
from dataclasses import dataclass

@dataclass(frozen=True)
class UserCredentials:
    username: str
    password: str

credentials = UserCredentials("user1", "securepassword")
# credentials.password = "newpassword"  # 這行會引發 dataclasses.FrozenInstanceError
```

#### 3. 排序功能
dataclass 可以透過 order=True 自動產生比較運算方法（如 <, >, <=, >=）
```python=
from dataclasses import dataclass, field

@dataclass(order=True)
class Person:
    name: str
    age: int = field(default=0)
    pets: list = field(default_factory=list)

p1 = Person("Alice", 30)
p2 = Person("Bob", 25)

# 排序比較
print(p1 > p2)  # True，因為 age 屬性進行排序
```

#### 4. 資料類別轉換為字典或元組
在使用 dataclass 時，若我們需要將資料物件轉換為字典或元組來進行處理或輸出。dataclass 提供了兩個方便的函式 asdict 和 astuple，分別將資料類別轉換為字典或元組，方便存取屬性值。這些方法會自動處理資料類別中的巢狀結構，但它們只在資料類別物件上可用。
```python=
from dataclasses import dataclass, asdict, astuple

@dataclass
class Person:
    name: str
    age: int
    city: str

# 建立 Person 物件
person = Person(name="Alice", age=30, city="New York")

# 將 Person 物件轉換為字典
person_dict = asdict(person)
print(person_dict)  
# 輸出: {'name': 'Alice', 'age': 30, 'city': 'New York'}

# 將 Person 物件轉換為元組
person_tuple = astuple(person)
print(person_tuple)  
# 輸出: ('Alice', 30, 'New York')
```

## 類別的繼承
繼承（Inheritance）是一種機制，允許一個新的類別（子類別）基於現有的類別（父類別）來定義，並繼承父類別的屬性和方法。

子類別可以擴展或覆寫繼承的屬性和方法。
```python=
# 定義一個基本的類別 Person
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        print(f"Hi, I'm {self.name} and I'm {self.age} years old.")


# 定義一個繼承自 Person 的子類別 Student
class Student(Person):
    def __init__(self, name, age, student_id):
        # 呼叫父類別的 __init__ 方法以初始化 name 和 age
        super().__init__(name, age)
        self.student_id = student_id

    # 覆寫父類別的方法
    def introduce(self):
        print(
            f"Hi, I'm {self.name}, I'm {self.age} years old, and my student ID is {self.student_id}."
        )


# 建立 Student 類別的實例
student = Student("Charlie", 22, "12345")

# 呼叫子類別的方法，它會覆寫父類別的同名方法
student.introduce()
```

### 多重繼承
在 Python 中，除了單一繼承，還可以使用多重繼承，即子類別可以繼承多個父類別的屬性和方法。這在某些情況下可以提高程式的靈活性，但同時也會增加複雜度，尤其是當多個父類別之間有重複的方法或屬性時，可能會出現方法解析順序（MRO）問題。
```python=
# 定義一個基本的類別 Worker
class Worker:
    def __init__(self, job_title):
        self.job_title = job_title

    def work(self):
        print(f"I am working as a {self.job_title}.")

# 定義一個基本的類別 Person
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        print(f"Hi, I'm {self.name} and I'm {self.age} years old.")

# 定義一個子類別 WorkingStudent，繼承自 Person 和 Worker
class WorkingStudent(Person, Worker):
    def __init__(self, name, age, student_id, job_title):
        # 呼叫兩個父類別的 __init__ 方法以初始化對應的屬性
        Person.__init__(self, name, age)
        Worker.__init__(self, job_title)
        self.student_id = student_id

    def introduce(self):
        print(f"Hi, I'm {self.name}, {self.age} years old, a student with ID {self.student_id}, and I work as a {self.job_title}.")

# 建立 WorkingStudent 類別的實例
working_student = WorkingStudent("Charlie", 22, "12345", "Software Developer")

# 呼叫繼承自 Person 和 Worker 的方法
working_student.introduce()  # 使用覆寫的方法
working_student.work()        # 繼承自 Worker 的方法
```
多重繼承適合在子類別需要結合多個獨立父類別的功能時使用。這些父類別之間應該彼此不依賴，且各自的功能應該是獨立的，例如上例中的 Person 和 Worker，分別代表不同的角色。

#### 方法解析順序（MRO）
在多重繼承中，當多個父類別有同名方法時，Python 會按照一個方法解析順序來確定哪個父類別的方法會被優先使用。可以使用 ClassName.mro() 來查看繼承的順序。

在單一繼承時，super() 通常用來呼叫父類別的方法。在多重繼承時，super() 的作用範圍會根據 MRO 來決定。因此，在多重繼承情況下需要更小心地使用 super()。
```python=
print(WorkingStudent.mro())
# 輸出：
# [<class '__main__.WorkingStudent'>, <class '__main__.Person'>, <class '__main__.Worker'>, <class 'object'>]
```

## 抽象類別 (Abstract Class)
在物件導向程式設計中，抽象類別是一個不能被實例化的類別，主要作為其他類別的基礎。它允許定義通用的介面或基本功能，並要求子類別實作特定方法。

Python 沒有像 Java 或 C# 這樣的明確介面 (interface) 關鍵字或概念，但可以使用抽象類別（Abstract Base Classes, ABCs）來達到類似的效果。Python 中的抽象類別允許定義必須由子類實現的抽象方法，從而實現介面的行為。這是在 Python 標準庫 abc 模組中實現的。

抽象類別適合用於以下情境：
1. 規範實作：當你希望強制規範某些子類別必須實作特定方法。
2. 避免重複程式碼：提供通用方法給不同子類別，減少重複的程式碼。
3. 多型 (Polymorphism)：可以使用抽象類別定義共同介面，讓不同的子類別實作該介面，但以不同方式處理細節。
```python=
from abc import ABC, abstractmethod

# 定義抽象類別
class Animal(ABC):

    @abstractmethod
    def sound(self):
        pass

# 子類別繼承抽象類別並實作抽象方法
class Dog(Animal):
    def sound(self):
        return "Bark"

class Cat(Animal):
    def sound(self):
        return "Meow"

# 實例化子類別並使用
dog = Dog()
cat = Cat()
print(dog.sound())  # 輸出: Bark
print(cat.sound())  # 輸出: Meow
```

除了抽象方法，抽象類別還可以包含具體方法，這些方法可供所有子類別使用。
```python=
from abc import ABC, abstractmethod

# 定義抽象類別，包含具體方法
class Vehicle(ABC):
    
    def __init__(self, name):
        self.name = name
    
    @abstractmethod
    def move(self):
        pass

    # 具體方法
    def start_engine(self):
        return f"{self.name}'s engine started"

# 子類別必須實作抽象方法 move()
class Car(Vehicle):
    def move(self):
        return f"{self.name} is driving"

class Boat(Vehicle):
    def move(self):
        return f"{self.name} is sailing"

# 實例化子類別並使用
car = Car("Car")
boat = Boat("Boat")
print(car.start_engine())  # 輸出: Car's engine started
print(car.move())          # 輸出: Car is driving
print(boat.start_engine()) # 輸出: Boat's engine started
print(boat.move())         # 輸出: Boat is sailing
```

## Meta 類別
> 本章節屬進階，且內容不保證完全正確，不影響程式的撰寫，可先跳過無妨。

在 Python 中，一切皆是物件的概念下，類別（class）也是物件的一種實例，所有類別的基礎類別是 Object，也就是父類別，但所有的類別(包含 Object)又都是由 Type 這個類別所建立的，因此 Type 稱之為 meta類別 (metaclass)。

一般情況下，所有的類別都是由 type 這個 metaclass 創建的，同時它們都是 object 這個基類的子類。這兩者共同構成了 Python 中類別的基礎結構。

在 Python 中，Object 和 Type 具有特殊的關係。
* object 類別： 所有類別的基類是 object。也就是說，所有類別（包括內建類別和使用者自定義的類別）都直接或間接地繼承自 object。 object 提供了一些基本的方法，例如 `__init__ 和 __str__`。
```python=
class MyClass:
    pass

print(isinstance(MyClass, object))  # True
```
* type 類別： 在 Python 中，type 是一個 metaclass，用於建立類別。同時，type 也是所有類別的基類，包括 object。 又因為 type 本身也是一個類別。所有的類別最終都是由 type 產生的，並且 type 自己也是自己的實例。
```python=
print(isinstance(type, object))  # True
print(isinstance(object, type))  # True
```
* Human 類別： 如果你有一個自定義的 Human 類別，它會繼承自 object，這是預設行為。同時，type(Human) 是 type 本身。
```python=
class Human:
    pass

print(issubclass(Human, object))  # True
print(type(Human) is type)  # True
```
因此，Human 類別的父類別是 object，同時 type(Human) 是 type。

總結來說，object 是 type 的實例，但同時也是所有類別的基類。在 Python 中，object 和 type 具有特殊的相互關係，形成了一個類別階層結構。

Human 是 type 的實例，而 Human 繼承了 Object
